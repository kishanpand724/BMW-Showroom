# BMW 3D Experience 🚗

An immersive 3D automotive website featuring cinematic scroll animations, realistic car visuals, interactive door-opening sequences, and a premium luxury-inspired design.

## ✨ Overview

BMW 3D Experience is an interactive automotive website designed to showcase a car through a cinematic browsing experience.

Instead of a traditional static website, it combines 3D visuals, smooth scrolling, camera movements, and interactive animations to create an engaging digital showroom.

## ⚙️ Installation

1. Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
```

2. Navigate to the project directory:

```bash
cd BMW-3D-Experience
```

3. Install dependencies:

```bash
npm install
```

4. Start the development server:

```bash
npm run dev
```

5. Open the local URL shown in your terminal.
